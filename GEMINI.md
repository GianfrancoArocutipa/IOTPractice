# GEMINI AGENT RULES - IOT PRACTICE REPO

Consulte y siga rigurosamente las instrucciones maestras detalladas en:
👉 [AGENTS.md](./AGENTS.md)

### Resumen Rápido de Ejecución ante "Resuélvelo" o subida de Guía IoT:
1. Crear carpeta: `fg_AAAA-MM-DD` (ejemplo: `fg_2026-11-17`).
2. Generar `README.md` (Paso a paso para Tinkercad con tabla de pines y componentes).
3. Generar `sketch.ino` (Código fuente C++/Arduino funcional).
4. Generar `diagram.json` (Esquema Wokwi con pines oficiales `esp:VIN`, `nano:2`, etc.).
5. Generar `libraries.txt` si requiere dependencias.
6. Ejecutar `git add .`, `git commit` y `git push origin main`.
